# 업무 리서치 기획 스킬 — Money&Works

막연한 산업 관심을 **판단할 질문 → 확인할 근거 → 실행할 행동**으로 구체화하는 학습자용 스킬 두 개.

Garry Tan의 gstack `office-hours`·`plan-ceo-review`를 참고·변형한 독립형 교육용 파생 작업이다. 공식 gstack·YC 교육판이 아니다. [출처·고정 버전·변경 내역](THIRD_PARTY_NOTICES.md), [MIT 라이선스](LICENSE).

## 두 가지 사용 장면

| 스킬 | 언제 사용하나 | 결과 |
|---|---|---|
| `mw-research-office-hours` | 무엇을 조사할지 아직 막연할 때 | 질문을 통해 만든 조사 계획 초안 |
| `mw-business-plan-review` | 조사·업무 개선 계획이 이미 있을 때 | 가치·근거·가정·범위·행동 점검과 수정 제안 |

기획 대화만으로 사용할 수 있다. gstack·Bun·Node.js·별도 브라우저·API 키·외부 플러그인을 요구하지 않는다. 실제 웹 조사에는 별도로 사용 가능한 검색 수단과 사용자의 조사 요청이 필요하다.

## 처음 사용하기 — Codex에서 이 폴더를 열기

Git이 있다면 복제한다. GitHub 계정이 없어도 공개 저장소를 읽거나 복제할 수 있다.

```text
git clone https://github.com/jch2100/mw-research-planning-skills.git
```

1. Codex에서 **복제한 `mw-research-planning-skills` 폴더**를 작업 폴더로 연다. 기존의 다른 프로젝트 폴더를 연 상태와 구분한다.
2. 새 대화를 시작하고 아래 요청을 입력한다. `.agents/skills`는 공식 저장소별 스킬 위치다. 이름이 목록에 안 보이면 앱을 다시 열거나 아래 직접 읽기 방법을 사용한다.
3. 생각을 평소 말투로 입력한다. 회사·고객 실명이나 정확한 매출은 필수가 아니다. 모르는 항목은 모른다고 말한다.

```text
$mw-research-office-hours
우리는 산업용 부품을 공급하고, 나는 영업을 담당합니다.
자동차 부품 고객이 많습니다. 내년 영업을 어디에 집중할지 고민입니다.
평소 고객사 홈페이지와 협회 뉴스를 봅니다. 영업 인력은 제한적입니다.
내가 답할 수 있게 질문부터 해주세요. 지금은 기획만 진행해 주세요.
```

계획이 나온 다음에는 다음처럼 요청한다.

```text
$mw-business-plan-review
위에서 만든 조사 계획을 검토해 주세요.
근거가 부족한 가정과 조사 범위를 먼저 점검하고,
우리 회사가 실행할 수 있는 작은 계획으로 다듬어 주세요.
계획에 대한 내 답과 AI의 제안은 구분해 주세요.
```

**스킬 인식이 안 될 때:** 다음과 같이 파일을 직접 읽도록 요청할 수 있다. 스킬 선택 목록에 자동 등록됐다는 뜻은 아니지만, 같은 지침으로 대화할 수 있다.

```text
.agents/skills/mw-research-office-hours/SKILL.md를 읽고 그 절차로 도와주세요.
```

ZIP 다운로드도 가능하다. 압축을 푼 폴더에 `.agents/skills`가 있는지 확인하고 그 폴더를 연다. 파일을 탐색기에서 실행하거나 스킬 내용을 명령창에 붙여 넣는 방식이 아니다.

공식 동작 근거: [OpenAI Build skills](https://learn.chatgpt.com/docs/build-skills). 다른 앱에서의 자동 검색·설치 방법은 이 릴리스에서 검증하지 않았다.

## 학습자가 준비할 입력

1. 회사가 제공하는 것과 내 역할
2. 주요 고객·고객 산업
3. 최근 판단하기 어려웠던 일
4. 평소 보는 사이트와 그곳에서 찾는 정보
5. 리서치 결과로 바꾸고 싶은 행동
6. 기한·인력·지역 등 중요한 제약

처음부터 전부 채울 필요는 없다. AI가 중요한 빈틈부터 질문한다. 모름은 조사할 과제가 되고, AI의 제안은 본인의 확정 답과 구분한다.

## 검증 도구 — 학습자 필수 아님

Python 3가 있는 강사·관리자만 다음 명령으로 패키지의 로컬 링크·라이선스·독립성을 확인할 수 있다. Python은 스킬 대화의 필수 조건이 아니다.

```text
python scripts/verify_package.py
```

스킬 지침은 모델의 행동을 안내하며, 실제 권한 통제를 대체하지 않는다. 호스트 앱의 권한·보안 설정을 유지한다. 강의 전에는 실제 학습자 계정으로 한 번 리허설한다.
