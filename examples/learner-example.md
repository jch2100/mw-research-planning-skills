# 가상 사례 — 영업 집중 대상을 정하는 리서치

아래는 교육용 작성 예시다. 실제 학습자·기업 정보나 독립 모델 실행 기록이 아니다.

## 학습자 초기 입력

> 우리는 산업용 자동화 부품을 공급하고 나는 영업을 담당합니다. 자동차 부품 고객이 많습니다. 내년 영업을 어디에 집중할지 고민입니다. 고객사 홈페이지와 협회 뉴스를 보지만, 우리에게 어떤 의미인지 연결하기 어렵습니다. 영업 인력이 적어 여러 산업을 동시에 공략하기 어렵습니다.

## 인터뷰에서 구체화할 부분

- 내년 산업 전체의 전망인지, 다음 전략 회의에서 영업 조사 대상 산업을 고르는 판단인지 확인한다.
- 고객 투자 발표, 자동화 필요, 제품 적합성 중 어떤 신호를 관찰할지 묻는다.
- 고객의 실제 예산·발주·도입 시점은 공개 발표와 구분해 직접 확인 과제로 남긴다.
- 조사 기간·지역·후보 산업 수는 학습자와 합의한다. AI가 예시 값을 확정 조건으로 바꾸지 않는다.

## 답변을 받아 확정했다고 가정한 계획 예시

| 항목 | 초안 |
|---|---|
| 판단할 질문 | 다음 전략 회의에서 추가 영업 조사를 진행할 고객 산업 하나를 고른다. |
| 회사 맥락 | 자동차 부품 고객 중심, 영업 인력이 제한적이라는 교육용 조건. 실제 매출·고객 비중은 미제공. |
| 대상·기간 | 학습자가 고른 후보 두 산업의 최근 공개자료. 지역·기간은 실제 수업에서 확인한다. |
| 관찰 신호 | 공개 투자·생산 계획, 자동화 필요가 드러난 과제, 우리 제품 적용 가능성. |
| 출처 | 고객사 공식 발표·공시·협회 자료를 후보로 제안. 아직 실제 접근을 검증하지 않음. |
| 핵심 가정 | 산업 투자 발표가 우리 제품 구매로 연결된다는 가정은 검증되지 않음. |
| 반대 근거 | 투자 목적이 우리 제품과 다르거나, 도입 시점·접근 경로가 맞지 않는 경우. |
| 다음 행동 | 제품 적합성을 내부 담당자와 확인하고, 알려진 고객에게 투자 목적·일정을 질문한다. |
| 성과 확인 | 원문이 연결된 후보 비교와 실제 확인 행동을 남긴다. 매출·이익은 실현 후 별도 기록한다. |
| 제외 | 전 산업 전수 조사, 고객 구매 의향 추정, 앱 기능 추가, 공개·회원·예약 설정. |

## 사업 관점 점검 예시

현재 초안에서 가장 큰 미정은 후보 산업과 조사 기간이다. 공개 투자 신호만으로 매출을 확정할 수 없고, 제품 적합성은 내부 확인이 필요하다. 먼저 후보 두 산업과 판단 시점을 정하면 제한된 조사를 진행할 수 있다. 이는 새 사이트 기능을 추가할 이유가 되지는 않는다.
