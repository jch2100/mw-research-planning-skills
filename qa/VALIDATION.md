# 검증 범위 — v0.1.0

이 파일은 확인한 사실과 남은 시험을 구분한다. 형식 검사나 저장소 복제를 대화 품질·보안 인증으로 해석하지 않는다.

## 수행하는 패키지 검사

- 공식 skill-creator의 `quick_validate.py`: 두 SKILL.md의 이름·설명·형식.
- `scripts/verify_package.py`: UTF-8, 로컬 자료 링크, 스킬별 원본 MIT 전문 해시, gstack 전용 시작 명령·훅 경로 미포함, UI 호출 이름, 실행 바이너리·셸 설치 파일 미포함.
- `scripts/check_discovery.py`: 새 Codex app-server 프로세스에서 저장소별 스킬 인식. 모델 대화·스킬 실행은 수행하지 않는다. 사용자 전역 환경에 gstack이 없다고 증명하는 검사는 아니며, 이 저장소를 발견 출처로 확인한다.
- 공개 후 별도 폴더로 다시 복제해 같은 검사를 반복한다.

## 2026-10-26 실행 결과

- 두 스킬 모두 공식 형식 검사 통과.
- 패키지 검사 통과: 각 지침 5,723바이트·4,894바이트, 원본 라이선스 해시 일치, 로컬 링크 정상.
- 새 Codex app-server 프로세스의 `skills/list`에서 두 스킬을 `repo` 범위·활성 상태로 인식함. 모델 turn은 0회다.
- 공개 후 복제 검증 결과는 릴리스 노트에 기록한다. 아래 행동 사례를 독립 실행 통과로 표시하지 않는다.

## 세 가지 사례의 작성자 검토

`tests/SCENARIOS.md`와 아래 입력·출력 예시는 작성자가 지침을 적용해 검토한 기록이다. 독립 모델 실행·실제 학습자 대화·질문 시간 측정은 아직 수행하지 않았다.

| 사례 | 작성자 검토에서 남길 결과 | 구분 |
|---|---|---|
| 막연한 목표 | 교육회사라는 맥락을 반복 질문하지 않고, 제안 주제를 정하는 판단을 먼저 구체화한다. 고객의 현장 적용 문의를 구매 의향으로 단정하지 않는다. 다음은 판단 시점·관찰 신호를 확인하는 질문이며 사이트 구현은 진행하지 않는다. | 지침 적용 검토 |
| 자료 부족 | 실명이나 없는 수치를 요구하지 않는다. 협회 자료는 후보로 표시하고, 현재 검색하지 않는다. 개별 고객의 투자 목적·일정은 직접 확인 과제로 남긴 초안을 제시한다. | 지침 적용 검토 |
| 과도한 범위 | 연구·화면·회원·결제·연동·예약을 구분하고 10분 완성을 보장하지 않는다. 작은 결과와 보류 기능을 제안하되 실제 제외는 미확정으로 남긴다. | 지침 적용 검토 |

## 아직 필요한 시험

- 새 대화에서 두 스킬을 각각 실제 호출한 독립 행동 시험.
- 새 학습자 계정과 Mac에서 클론·폴더 열기·스킬 호출 리허설.
- 한국어 질문 난이도·교실 소요 시간·중도 종료·요청 변경을 실제 대화로 관찰.

현재 릴리스는 수업 전 리허설용이다. 실제 배포 자료에 개인정보·사내 문서·API 키를 넣지 않는다. 모델의 지침 준수는 실행 권한 통제의 대체 수단이 아니다.
